# @rifter/web

Angular SPA for Rifter (post-match analysis, reports, 2D fragment player).

## Commands

Run from the repo root via `pnpm -C apps/web <script>`:

- `pnpm -C apps/web start` — dev server on :4200
- `pnpm -C apps/web build` — production build to `dist/web/`
- `pnpm -C apps/web test` — unit tests (Vitest via `@angular/build:unit-test`)

No e2e runner is configured yet.
